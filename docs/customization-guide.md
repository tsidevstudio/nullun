# Nullun Customization Guide

This document covers public, user-visible customization concepts only.

## Battery

Set the battery level used in your status-bar design.

## Carrier and network

Customize visible carrier and mobile-network indicators where supported by the selected layout.

## Signal and Wi-Fi

Choose the visual indicators that best match the result you want to create.

## Messages and app name

Nullun allows additional visible text to be incorporated into supported designs.

## Backgrounds

Use supported background controls to adjust the appearance of your composition.

## Preview and History

Preview is intended for checking your design before external output.

History helps you revisit previous work.

This repository does not publish internal rendering logic or implementation details.
