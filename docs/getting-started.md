# Getting Started with Nullun

Nullun is a Status Bar Studio for Android.

## What you can do

- Create custom status-bar visuals
- Adjust battery percentage
- Customize carrier text
- Configure signal, Wi-Fi and network indicators
- Add custom messages
- Adjust app-name display
- Customize backgrounds
- Preview your work
- Use History for previous work

## Access model

Creation, editing, preview and History are available without a subscription.

External output is available through the Lifetime unlock.
