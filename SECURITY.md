# Nullun Security Policy

This repository contains public product information and documentation for Nullun.

## Reporting a security issue

If you believe you have found a security vulnerability or privacy-sensitive defect, report it privately:

**support@tsidevstudio.com**

Please do not publish exploit details, proof-of-concept material or sensitive technical findings in public GitHub Issues before TSI Dev Studio has had a reasonable opportunity to review them.

## Responsible reporting

Please:

- Test only on devices and data you are authorized to use
- Avoid accessing, modifying or deleting another person's data
- Avoid actions that could affect availability for other users
- Avoid social engineering or phishing
- Avoid public disclosure before review

## Repository scope

This repository does not publish private implementation details, internal architecture or other security-sensitive technical information.

Nullun is not a security product. Security documentation focuses on responsible reporting of application issues and safe public disclosure.
